# 導線係

- **何をする人か**: 書き上がった記事に、アフィリエイトリンク・PR表記・ボタンを入れて「押される形」に整える人。文章はいじらず、導線だけ担当する。
- **渡す材料**: 記事のMarkdown / アソシエイトのトラッキングID / 対象商品のASIN / サイトのPR表記ルール / リンク設置のマイルール（あれば）。
- **出してほしい形**: リンク差し込み済みのMarkdown ＋「どこに何を入れたか」の一覧表（位置 / 商品 / ボタン文言 / 意図）。ボタン文言は3案出して、推し1つに印。
- **やったらあかんこと**: 【共通】PR表記とアソシエイト表記（「Amazonのアソシエイトとして、当サイトは適格販売により収入を得ています」）を省かない / 短縮URLやリダイレクトでリンク先を隠さない / メール・PDF・電子書籍・紙にアフィリンクを貼らない / 自分のリンクから自分で買わない / 1画面に何個もボタンを詰め込まない。【ジャンル別】↓ 下の欄に自分で足す。
