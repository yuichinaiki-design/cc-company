# 役割パック: Amazonアフィリエイト

Amazonアフィリエイトを回すための「係」4人分。1ファイル1人。

**想定ジャンル: デスク周り・作業道具 ＋ Amazonデバイス**

## なぜ2本立てか

この2つは性質が逆です。

| | 単価 | 紹介料率 | 書きやすさ |
|---|---|---|---|
| デスク周り・作業道具 | 高い | 低いカテゴリ | 毎日使っているので書ける |
| Amazonデバイス | 低い | 高いカテゴリ | 使っていれば書ける |

片方に寄せると、単価か料率のどちらかを捨てることになります。だから `01-research.md` は、10件の候補にAmazonデバイスを最低2件混ぜるよう指定しています。
`04-numbers.md` で種別ごとに小計を出しているのも同じ理由で、料率の違うものを混ぜて平均すると判断を誤るためです。

もう1つ違うのが時間軸です。デバイスはセール時に大きく動くので、セールの時点で記事がすでに検索で拾われている必要があります。
記事が載るまでの時間を逆算すると、デバイス記事には公開の締め切りがある一方、道具にはこの制約が薄い。
`01-research.md` の優先度をこの順で付けるのはそのためです。

紹介料率の具体的な数字は変わります。運用前にアソシエイトの「紹介料率」ページで確認してください。

## 4人と受け渡し

```
ネタ探し係 → 記事を書く係 → 導線係 → 数字を見る係 → （ネタ探し係へ戻る）
```

| ファイル | 係 | ひとことで |
|---------|---|-----------|
| `01-research.md` | ネタ探し係 | 次に書く商品とキーワードを決める |
| `02-writer.md` | 記事を書く係 | 読者が選べる記事にする |
| `03-link.md` | 導線係 | リンク・PR表記・ボタンを入れる |
| `04-numbers.md` | 数字を見る係 | 数字を見て次に直す1箇所を決める |

## 中身の形

どのファイルも4行だけ。

1. **何をする人か** — 担当範囲
2. **渡す材料** — こちらが用意するインプット
3. **出してほしい形** — アウトプットの型（表・行数・列まで指定する）
4. **やったらあかんこと** — NG

## 使い方

1. `.company/affiliate/roles/` にコピーする
   （`affiliate` 部署がなければ、秘書に「アフィリエイト運営部門を作って」と言えば生成されます。
   `research/` `articles/` `reports/` が一緒に作られ、各係の出力の置き場になります）
2. 上から読んで、合わない行だけ書き換える（ゼロから書くより速い）
3. **各ファイル末尾の「ジャンル別のNG」だけは自分で埋める**

3 が一番大事。4行目の【共通】は Amazonアソシエイト規約・ステマ規制まわりの、どのジャンルでも効く分だけ書いてあります。
あなたの現場固有の地雷（読者に誤解された点、問い合わせが来た点）はAIが知らないので、そこは自分の言葉で足してください。

## 別ジャンルで使うとき

`genre:` の行と、`01` の表の列・`04` の種別まわりを差し替えれば、他のジャンルにも転用できます。4行フォーマットはそのまま使えます。

## 注意

4行目の【共通】は執筆時点の一般的な内容です。アソシエイトの運営規約と景品表示法は変わるので、運用前に一次情報を確認してください。
