# 役割パック: Amazonアフィリエイト

Amazonアフィリエイトを回すための「係」4人分。1ファイル1人。

## 4人と受け渡し

```
ネタ探し係 → 記事を書く係 → 導線係 → 数字を見る係 → （ネタ探し係へ戻る）
```

| ファイル | 係 | ひとことで |
|---------|---|-----------|
| `01-research.md` | ネタ探し係 | 次に書く商品とキーワードを決める |
| `02-writer.md` | 記事を書く係 | 読者が選べる記事にする |
| `03-link.md` | 導線係 | リンク・PR表記・ボタンを入れる |
| `04-numbers.md` | 数字を見る係 | 数字を見て次に直す1箇所を決める |

## 中身の形

どのファイルも4行だけ。

1. **何をする人か** — 担当範囲
2. **渡す材料** — こちらが用意するインプット
3. **出してほしい形** — アウトプットの型（表・行数・列まで指定する）
4. **やったらあかんこと** — NG

## 使い方

1. `.company/[部署]/roles/` にコピーする
2. 上から読んで、自分のジャンルに合わない行だけ書き換える（ゼロから書くより速い）
3. **各ファイル末尾の「ジャンル別のNG」だけは自分で埋める**

3 が一番大事。4行目の【共通】には、Amazonアソシエイト規約やステマ規制まわりの、どのジャンルでも効く分だけ書いてある。
ジャンル固有の地雷（言ってはいけない効能、触れてはいけない比較、業界の慣習）はAIが知らないので、そこは自分の言葉で足す。

## 注意

4行目の【共通】は執筆時点の一般的な内容。アソシエイトの運営規約と景品表示法は変わるので、運用前に一次情報を確認すること。
