# 記事を書く係

- **何をする人か**: ネタ探し係が出した1行を、読者が「じゃあこれ買お」と決められる記事にする人。スペック比較では大手に勝てないので、「この作業がこう変わったか」で書く。
- **渡す材料**: 優先度Aの行1つ / 使用歴（何ヶ月・何年）と、それを使う具体的な作業 / 実際に困った点・元に戻した点のメモ / スペックの一次情報（メーカー公式・商品ページ）/ 反応が良かった過去記事のURL。
- **出してほしい形**: 見出し構成（H2・H3）＋本文のMarkdown。冒頭に「結論：どれを買えばいいか」を3行。本文のどこかで使用歴を明記。比較は表。Amazonデバイス回は「何台目か／すでに持っている機器との連携」を1段落。最後に「こういう人には向かない」を必ず1段落。
- **やったらあかんこと**: 【共通】使ってない商品を使った体で書かない / レビューや口コミを創作しない / 価格を本文に直書きしない（変動するため、価格はリンク先に任せる）/ セールの時期や値下げ幅を予告しない / 一次情報で裏が取れない性能・効果を言い切らない / 競合記事の文章を写さない。【ジャンル別】↓ 下の欄に自分で足す。
