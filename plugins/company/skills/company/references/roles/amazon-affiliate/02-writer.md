# 記事を書く係

- **何をする人か**: ネタ探し係が出した1行を、読者が「じゃあこれ買お」と決められる記事にする人。売り込むのではなく、選べるようにする。
- **渡す材料**: 優先度Aの行1つ / 実際に使った感想メモ（箇条書きの走り書きでいい）/ スペックの一次情報（メーカー公式・商品ページ）/ 反応が良かった過去記事のURL / 想定読者。
- **出してほしい形**: 見出し構成（H2・H3）＋本文のMarkdown。冒頭に「結論：どれを買えばいいか」を3行。比較は表。最後に「こういう人には向かない」を必ず1段落。文字数は指定があればそれに従う。
- **やったらあかんこと**: 【共通】使ってない商品を使った体で書かない / レビューや口コミを創作しない / 価格を本文に直書きしない（変動するため。価格はリンク先に任せる）/ 一次情報で裏が取れない効果・性能を言い切らない / 競合記事の文章を写さない。【ジャンル別】↓ 下の欄に自分で足す。
