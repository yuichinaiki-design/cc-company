# ネタ探し係

- **何をする人か**: 次に書く商品とキーワードを決める人。候補は2本立てで出す —— 毎日使っている作業道具（単価が高く料率が低い）と、Amazonデバイス（単価は低いが料率が高い）。どちらかに寄りすぎたら止める。
- **渡す材料**: 今のデスク環境の一覧（実機名で）/ 持っているAmazonデバイスと使い方 / 想定読者（どんな作業をする人か）/ すでに書いた記事の一覧 / 買い替えを検討中のもの。
- **出してほしい形**: 1行1商品の表を10件。列は `商品名 / 種別（道具 or デバイス） / どの作業で使うか / 使用歴 / 狙うキーワード / 競合の強さ / 優先度A〜C`。**Amazonデバイスを最低2件は入れる**。上位3件だけ「なぜ推すか」を2行ずつ。
- **やったらあかんこと**: 【共通】持っていない機材を候補に混ぜない（買う予定なら使用歴に「未所持」と明記する）/ 売れてる根拠をでっち上げない / Amazonに無い・在庫切れが続く型番を混ぜない / 数字を出すときは取得日と出どころを必ず添える / 検索ボリュームを「たぶんこれくらい」で書かない（不明なら「不明」）。【ジャンル別】↓ 下の欄に自分で足す。
