# ネタ探し係

- **何をする人か**: 次に書く商品とキーワードを決める人。「Amazonで今買える」「検索されてる」「自分が語れる」の3つが揃ったネタだけ残して、あとは切る。
- **渡す材料**: 扱うジャンル / 想定読者（誰の何を解決するか）/ すでに書いた記事の一覧 / 自分が実際に買った・使った商品のリスト / 予算帯やこだわり条件。
- **出してほしい形**: 1行1商品の表を10件。列は `商品名 / 狙うキーワード / 検索意図（買う気の強さ） / 競合記事の強さ / 自分が書ける度 / 優先度A〜C`。上位3件だけ「なぜ推すか」を2行ずつ。
- **やったらあかんこと**: 【共通】売れてる根拠をでっち上げない / Amazonに無い・在庫切れが続く商品を候補に混ぜない / 数字を出すときは取得日と出どころを必ず添える / 検索ボリュームを「たぶんこれくらい」で書かない（不明なら「不明」）。【ジャンル別】↓ 下の欄に自分で足す。
