# assets/

Put a single still image here named `background.jpg` (or update
`config.yaml > video.background_image`). It will be stretched/letterboxed
to the configured `width x height` and used as the video's only frame.

If the file is missing, `src/video.py` generates a solid color image so the
pipeline still runs.

Recommended:
- 1920x1080 JPEG, < 1 MB
- High contrast but visually calm (gradient, lo-fi illustration, etc.)
- You own the copyright, or it is CC0 / licensed for commercial use.
